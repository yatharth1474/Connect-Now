ConnectNow is a full-stack educational platform designed for seamless online learning and collaboration between educators and students. The platform allows instructors to create and sell courses while providing students with interactive learning tools and real-time communication features.

Features
📚 Course selling and management system
👨‍🏫 Instructor and student authentication
💬 Real-time chat room for discussions and collaboration
🎥 Video calling feature for live classes and meetings
📝 Notes sharing with database history tracking
🔍 Organized course browsing and learning dashboard
📂 Secure database storage for user data and shared resources
⚡ Responsive and user-friendly interface
Tech Stack
Frontend: React
Backend: Node JS
Database: Mongo DB
Real-time Communication: Socket.io / WebRTC
Authentication: JWT / Firebase / OAuth
Purpose

The goal of this project is to create an interactive and scalable e-learning environment where educators can monetize their knowledge and students can learn, communicate, and collaborate efficiently.
